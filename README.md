# aprendiendo-react-Buscador-Peliculas
# Buscador de Películas

# Aplicación web desarrollada con React y TypeScript que permite buscar películas utilizando una API externa.

# Tecnologías
- React
- TypeScript
- CSS
-Fetch API

# Funcionalidades
- Buscar películas por título
- Consumo de API REST
- Manejo de peticiones asíncronas
- Visualización de resultados
- Manejo de errores y búsquedas sin resultados
